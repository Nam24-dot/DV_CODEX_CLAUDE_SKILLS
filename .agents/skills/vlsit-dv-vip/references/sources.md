# Source hierarchy

Use the installed VIP release's user guide, API reference, release notes, compatibility matrix and shipped examples as the authority for actual classes, fields, callbacks, commands and supported modes. Then apply the selected protocol specification and project integration contract.

Public vendor entry points:
- [Synopsys Verification IP](https://www.synopsys.com/verification/verification-ip.html)
- [Cadence Simulation VIP](https://www.cadence.com/en_US/home/tools/system-design-and-verification/verification-ip/simulation-vip.html)
- [Accellera UVM resources](https://www.accellera.org/downloads/standards/uvm)

These are discovery references, not evidence of a specific installed release's capabilities. Apply the same workflow to Siemens, other commercial suppliers and internal/open-source VIP using their actual documentation. No vendor packages, license material or restricted manuals are bundled here.
