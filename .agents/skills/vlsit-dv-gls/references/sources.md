# Sources and compatibility

- [Cornell ASIC tools tutorial](https://github.com/cornell-ece5745/ece5745-tut4-asic-tools/blob/main/docs/index.md) demonstrates a concrete RTL-to-gates flow and SDF-backed simulation. Its commands are examples for that environment, not portable simulator defaults.
- Use the installed simulator's SDF annotation and timing-check documentation, the delivered cell-library model documentation and the project's timing methodology as the command/option authority.

Record the exact tool, library and artifact versions used. This skill does not redistribute standard-cell models or prescribe commercial simulator switches. Delay annotation, static timing analysis and functional equivalence answer different questions.
