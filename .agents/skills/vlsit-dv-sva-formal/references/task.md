# Temporal review checklist
For each property record antecedent, consequent, first/last permitted response cycle, disable condition, clock and X policy. Explain whether reset aborts an outstanding obligation or should itself be checked by a separate property.

A ready/valid source commonly must retain valid and payload while stalled, but confirm the actual protocol contract before writing this requirement. Do not turn a receiver obligation into an assumption on the DUT.

Cover the antecedent and relevant corner sequences. In formal, check that reset can release and useful traffic can occur under assumptions. Bounded no-counterexample results need the bound; unbounded claims need explicit successful proof evidence from the tool.

CDC/RDC structural and metastability analysis are separate from single-clock SVA. Multi-clock properties require tool-specific semantics and a justified model; do not claim CDC sign-off from ordinary simulation.
