# Acceptance review
Required inputs: authoritative criteria/version; DUT/TB/spec identity; supported configurations; requirement denominator; raw regression/coverage/proof evidence; defects/waivers; designated approver.

Report these axes separately: artifact completeness; executed check outcomes; requirement closure; coverage metrics; accepted risks; human approval. VERIFIED_IN_SCOPE describes check results, while READY_FOR_REVIEW only recommends human review.

A passing regression with missing requirement checks is not complete DV. A high functional coverage number with disabled scoreboards is not adequate evidence. Keep NOT_RUN and INCONCLUSIVE visible in the summary and do not convert them to N/A.
